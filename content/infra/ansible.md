Ansible is used for Infrastructure-As-Code (IAC) management of the homelab. In general, all configuration changes or deployments **should** be done through Ansible. This lets the homelab be easily reproducable.

The entire repo for Ansible playbooks can be found on the [[Github|https://github.com/jtwylde/jordanhome-iac]]

Details for using & setting up the repo can be found in the [[README|https://github.com/jtwylde/jordanhome-iac/blob/main/README.md]] of the repo
